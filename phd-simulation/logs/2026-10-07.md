## 09:15–10:15 — Source-check the comparison rule

IBM's current `Statevector` documentation describes its `equiv` operation as comparison up to global phase. Today's [acceptance note](../docs/statevector-acceptance.md) records that primary source and defines a local, inspectable comparison rule. The new harness selects the largest-magnitude reference amplitude, infers one complex phase factor from it, and then checks every component after applying that factor.

The local implementation is not presented as a reimplementation audit of Qiskit. It is an independent acceptance oracle with the same stated equivalence goal. The distinction matters because Qiskit was not imported or executed.

## 10:15–11:30 — Pin the index contract first

Before evolving any state, the code checks the index formula \(j=\sum_i b_i2^i\). Index 3 must represent logical bits `(1,1,0,0,0,0)` with q0 first. This asymmetric fixture is carried forward from the earlier mapping work. A round-trip test alone could let two reversed components agree with each other; the fixed known example breaks that symmetry.

The deterministic initial vector contains 64 nonzero complex amplitudes. That makes every basis component observable to the comparison, while avoiding randomness and seeds. It is normalized once and evolved at \(\pi/17\), 0.2 and 0.7 using the independent residual energies and the mapped Ising energies.

## 11:30–12:00 — Fictional Netherlands mapping discussion

In a simulated discussion, the Netherlands circuit-mapping role challenges the phrase “the vectors match.” The decision is to maintain two acceptance modes. When both implementations retain the constant offset, strict element-by-element equality is required. When the circuit intentionally omits the offset, one unit-modulus global phase may be removed before comparing every amplitude. No real scientist or institution participated.

The role also asks whether equal measurement probabilities would be enough. The answer is no. A sign error can preserve all computational-basis probabilities immediately after a diagonal cost layer while corrupting relative phases that a later mixer converts into different probabilities. The acceptance test must therefore inspect complex amplitudes, not just counts.

## 12:00–12:30 — Lunch and a failed naive criterion

The useful failure today is an intentionally naive strict comparison. For the three offset-free statevectors, the largest component distances from the reference are 0.3014, 0.2902 and 0.2953. A direct equality assertion would reject every case even though each difference is exactly the predicted global phase.

After phase alignment, the largest residual falls to \(1.84\times10^{-15}\). The recovered phase agrees with \(e^{+i\gamma 50}\) to the same scale. This result supports the acceptance rule for this fixture; it does not prove numerical robustness for arbitrary near-zero or noisy statevectors.
