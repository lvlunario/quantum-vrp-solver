## 12:00–13:30 — Read the interface documentation carefully
IBM's primary documentation is checked again for basis ordering and the Pauli Z matrix. The local contract assigns x0 to the least significant bit and displays the highest-index bit on the left. The optimal logical assignment [1,1,0,0,0,0] therefore has display string `000011`. The note now also flags that primitive output conventions can differ, so this plain-Python decoder cannot be assumed to handle every future SDK result.

That caveat changes the next integration requirement: before decoding an actual primitive output, select its documented representation and verify an asymmetric known state. A successful encode/decode round trip is insufficient if both halves share the same mistaken convention. No claim is made that Qiskit integration has been tested today.

## 13:30–15:00 — Failures that the audit can expose
The deliberate reversed-display fault changes 56 of the 64 energies. Reversing the local-field signs changes all 64. Omitting the constant offset shifts every energy by 50 while preserving the winning assignment. These are executed fault injections, not accounts of accidental historical bugs. Their counts describe this toy only and cannot be advertised as a general software fault-detection rate.

The lesson for the manuscript is precise: checking the winning decision and checking objective values are different acceptance criteria. The offset example passes the former and fails the latter. The [mapping note](../docs/ising-mapping.md) records both the algebra and the evidence, without claiming novelty or quantum advantage.
