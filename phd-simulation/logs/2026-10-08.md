## 09:15–10:45 — Coursework: turn commuting Pauli terms into gates

The cost Hamiltonian contains a constant, six local Z fields and fifteen ZZ couplings. All of these operators are diagonal, so they commute. Their exponential can therefore be written as a product without a Trotter approximation for this Hamiltonian. Under the documented Qiskit definitions, each local term uses `RZ(2*gamma*h_i)` and each pair term uses `RZZ(2*gamma*J_ij)`.

The constant offset of 50 is placed in `QuantumCircuit.global_phase` as `-gamma*50`. A second circuit omits that phase on purpose. The [technical derivation](../docs/qiskit-cost-circuit.md) records the construction and source links, while the earlier independent energy and statevector oracles remain outside the SDK implementation.

## 10:45–12:00 — Build a circuit that can fail visibly

The new [Qiskit audit source](../src/verify_qiskit_cost_circuit.py) creates six qubits, six RZ gates and fifteen RZZ gates. It evolves the same deterministic 64-amplitude fixture at \(\pi/17\), 0.2 and 0.7. Qiskit is responsible for circuit evolution; the reference remains the capacity-residual energy evaluated for each logical bit assignment.

The index-3 fixture is checked before evolution: index 3 must mean logical bits `(1,1,0,0,0,0)` with q0 first. This is a small systems-engineering habit—verify the interface assumption before interpreting the higher-level result.

## 12:00–12:30 — Lunch and one discarded shortcut

The tempting shortcut is to compare only measurement probabilities. That would miss every phase error immediately after a diagonal cost circuit. Another tempting shortcut is strict statevector equality. That would falsely reject the circuit when the constant offset is intentionally omitted.

The acceptance logic therefore keeps both criteria: strict component equality when the offset is included, and equivalence up to one global phase when it is omitted. The comparison is not relaxed for relative-phase errors.

## 12:30–14:30 — Execute the SDK boundary test

The actual run produces [raw JSON evidence](../results/2026-10-08-qiskit-cost-circuit.json). All nine checks pass. Across the three angles, the full Qiskit circuit agrees with the independent oracle to a maximum component error of \(1.52\times10^{-15}\). All three offset-free circuits pass `Statevector.equiv`.

The naive strict comparison fails those same valid offset-free cases, with component distances from 0.2902 to 0.3014. That repeats yesterday's predicted failure using an actual SDK circuit rather than only the NumPy acceptance harness.

## 14:30–15:30 — Remove one interaction and reverse two conventions

Three deliberate circuit mutations are evaluated at \(\gamma=0.2\). Reversing the exponent sign is rejected. Mapping every logical qubit to the reversed physical index is rejected. Removing the RZZ term for coupling \(J_{01}=6\) is also rejected. These are injected faults, not accidental debugging stories, and passing this small set does not establish broad mutation coverage.

The operation-count assertion provides another guardrail: every unmutated cost circuit must contain six RZ and fifteen RZZ operations. The output vector remains normalized with norm squared 1.0.

## 15:30–16:30 — Close only the ideal cost-layer boundary

R12 is now complete for an ideal exact-statevector cost circuit in the pinned environment. That is narrower than “QAOA works.” There is no mixer, sampling, parameter search, transpilation, noise model or hardware result. Full-text QAOA reading also remains open.

Friday's work should turn this week's evidence into a compact methods-and-limitations section and decide the acceptance conditions for the mixer milestone. Advancing to optimization before that review would make the evidence chain harder to inspect.

**Plain language:** the mathematical score, hand-built acceptance oracle and real Qiskit cost circuit now agree. The test also catches three intentionally broken circuits, but it says nothing yet about whether QAOA finds a good microgrid decision.
